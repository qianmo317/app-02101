# 网易云音乐 - Vue 前端项目

## 原始题目

帮我用vue写一个网易云界面，要求有登录界面，登录进入后有首页，搜索和个人中心页面

### 项目要求

使用 Vue 3 + Vite 构建一个仿网易云音乐的移动端前端应用，要求实现以下功能：

1. **登录页面**
   - 手机号+密码登录
   - 表单验证（手机号格式、密码长度）
   - 登录状态持久化

2. **首页**
   - Banner 轮播图（自动播放）
   - 推荐歌单展示
   - 新歌推荐列表

3. **搜索页面**
   - 搜索框（支持防抖）
   - 搜索历史记录（本地存储）
   - 热门搜索推荐
   - 搜索结果展示

4. **个人中心**
   - 用户信息展示（头像、昵称、等级等）
   - 用户统计数据（听歌数、粉丝数、关注数）
   - 我的音乐列表
   - 创建的歌单列表
   - 退出登录功能

5. **技术实现要求**
   - 使用 Vue 3 Composition API
   - 使用 Vue Router 实现路由导航和路由守卫
   - 使用 Pinia 进行状态管理
   - 使用 Docker 进行容器化部署
   - 支持跨平台构建（ARM/AMD64）

6. **交互要求**
   - 所有可点击元素需要有交互反馈
   - 数据加载需要显示加载状态
   - 错误情况需要友好的错误提示

## How to Run

### Docker 方式（推荐）

```bash
# 构建并启动服务
docker-compose up --build -d

# 查看服务状态
docker-compose ps

# 停止服务
docker-compose down
```

### 本地开发

```bash
cd frontend-user
npm install
npm run dev
```

## 项目介绍

这是一个仿网易云音乐的 Vue 3 前端项目，采用 Vite 构建，实现了以下核心功能：

### 功能模块

- **登录页面**：手机号+密码登录，表单验证，登录状态持久化
- **首页**：Banner 轮播、快捷入口、推荐歌单、新歌推荐
- **搜索页面**：搜索框、搜索历史、热门搜索、搜索结果展示
- **个人中心**：用户信息展示、音乐服务入口、我的音乐、创建的歌单、退出登录

### 技术栈

- Vue 3 + Composition API
- Vue Router 4（路由守卫）
- Pinia（状态管理）
- Vite 5（构建工具）
- Nginx（生产环境部署）
- Docker（容器化部署）

### 项目结构

```
frontend-user/
├── src/
│   ├── views/          # 页面组件
│   │   ├── Login.vue   # 登录页（包含错误处理）
│   │   ├── Home.vue    # 首页（异步加载数据）
│   │   ├── Search.vue  # 搜索页（防抖搜索）
│   │   └── Profile.vue # 个人中心
│   ├── layouts/        # 布局组件
│   ├── router/         # 路由配置
│   ├── stores/         # 状态管理
│   └── styles/         # 全局样式
├── App.vue             # 根组件（包含页面切换动画）
├── Dockerfile          # Docker 构建文件
├── nginx.conf          # Nginx 配置
└── package.json        # 项目依赖
```

## 工程细节

- **模拟数据交互**：各页面组件通过异步函数（Promise & setTimeout）模拟真实 API 请求，具备加载状态切换和错误捕获逻辑，方便后续接入真实接口。
- **错误处理**：登录页面支持业务级错误提示（如手机号未注册）。
- **交互体验**：添加了全局页面切换动画，搜索框支持防抖处理。
- **日志记录**：关键业务逻辑（登录、搜索、数据加载）均有控制台日志输出，便于调试。
